# Пакет промпта: sigma-mes-skills 0.11.0 для ChatGPT и Codex

Пакет описывает, как сгенерировать новую версию плагина `sigma-mes-skills` для ChatGPT (режимы Codex и Work в десктопном приложении) и Codex (CLI, IDE). Плагин поддерживает три роли Конституции разработки СИГМА.MES+ и правила гейтов:

- ROLE-PRODUCT-OWNER — владелец продукта;
- ROLE-FUNCTIONAL-ARCHITECT — функциональный архитектор;
- ROLE-TECHNICAL-ARCHITECT — технический архитектор;
- правила гейтов GATE-01–GATE-06 (подготовка пакета гейта, заключения ролей, запись решения).

Основание — Конституция разработки СИГМА.MES+ редакции 0.9 (черновик) и Регламент функциональной приёмки редакции 0.1 (черновик). Плагин переписывается по правилам Конституции, а не подстраивается под версию 0.10.0.

## Исполнитель

Промпт написан для Claude CLI с моделью Sonnet. Поэтому все решения приняты заранее (файл `01-DECISIONS.md`), шаги пронумерованы, у каждого шага есть проверка, додумывать запрещено. Всё, что не описано в пакете, исполнитель записывает в `OPEN-QUESTIONS.md` плагина и не реализует.

## Порядок чтения

1. `00-MASTER-PROMPT.md` — главный промпт: цель, входы, шаги, запреты, отчёт.
2. `01-DECISIONS.md` — предрешённые решения с основаниями.
3. `context/` — нормативная и среда исполнения:
   - `constitution-v0.9.extract.yaml` — дословное извлечение Конституции 0.9;
   - `acceptance-regulation-v0.1.extract.yaml` — дословное извлечение Регламента функциональной приёмки 0.1;
   - `federated-model.yaml` — федеративная модель применения ИИ: рабочее место, VPN, защищённый сегмент;
   - `platform-openai.yaml` — формат пакета плагина OpenAI и настройка MCP, с источниками;
   - `ai-use-conditions.draft.yaml` — проект условий применения ИИ по RULE-AI-001 (не утверждён).
4. `spec/` — что именно создать:
   - `plugin-layout.md` — структура файлов плагина;
   - `session-protocol.md` — обязательный протокол начала и ведения сеанса для всех навыков;
   - `skill-product-owner.md`, `skill-functional-architect.md`, `skill-technical-architect.md`, `skill-gates.md` — спецификации навыков;
   - `artifacts.yaml` — схемы артефактов, которые создают навыки;
   - `config-template.yaml` — шаблон конфигурации рабочего репозитория.
5. `checks/` — приёмка сгенерированного плагина:
   - `structural-checks.md` — структурные проверки для `run-all.sh`;
   - `normative-checks.yaml` — разрешённые коды и запреты;
   - `scenario-tests.md` — поведенческие сценарии для ручной проверки в Codex.
6. `tools/extract_constitution.py` — скрипт извлечения (проверен на Конституции 0.9 и Регламенте 0.1).
7. `AUDIT.md` — результаты независимого аудита этого пакета.
8. `OPEN-QUESTIONS.md` — вопросы к людям, которые не блокируют генерацию.

## Запуск

В корне репозитория плагина (`sigma-mes-methodology`):

```
claude --model sonnet
```

Первое сообщение исполнителю:

```
Прочитай пакет в каталоге prompt/0.11.0/ целиком в порядке из README.md.
Выполни 00-MASTER-PROMPT.md шаг за шагом. Не пропускай проверки шагов.
```

Пакет кладётся в репозиторий в каталог `prompt/0.11.0/` до запуска.
