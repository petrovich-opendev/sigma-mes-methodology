# sigma-mes-skills 0.11.0

## Назначение

Плагин готовит материалы ролей Конституции разработки СИГМА.MES+ и пакеты гейтов в формате Agent Plugins — для ChatGPT (режимы Codex и Work в десктопном приложении) и Codex (CLI, IDE). Работа идёт в локальном агенте с доступом к файлам рабочего репозитория через VPN.

## Навыки и режимы

### sigma-product-owner — ROLE-PRODUCT-OWNER

- PO-1. Описание продукта.
- PO-2. Развитие работающего продукта.
- PO-3. Разногласие функциональных архитекторов.
- PO-4. Вариант для предприятия.
- PO-5. Ответственный за общие элементы функциональной архитектуры.
- PO-6. Предложение об изменении Конституции.
- PO-7. Заключение владельца продукта и решение по GATE-01.

### sigma-functional-architect — ROLE-FUNCTIONAL-ARCHITECT

- FA-1. Функциональная архитектура модуля.
- FA-2. Исследование практик (метод работы).
- FA-3. Концепт интерфейса и макеты.
- FA-4. Функциональные требования.
- FA-5. Требования к качеству.
- FA-6. Предметные термины.
- FA-7. Сквозные сценарии.
- FA-8. Тест-дизайн (пока ROLE-TEST-ENGINEER не назначен).
- FA-9. Функциональная приёмка.
- FA-10. Изменение функциональной архитектуры.
- FA-11. Заключения к гейтам.
- FA-12. Достаточность функциональной архитектуры и журнал вопросов.

### sigma-technical-architect — ROLE-TECHNICAL-ARCHITECT

- TA-1. Техническое архитектурное решение (ADR).
- TA-2. Модель C4 (Structurizr DSL).
- TA-3. Архитектура развёртывания.
- TA-4. Обеспечение требований к качеству.
- TA-5. Интеграционная архитектура.
- TA-6. Проверка отнесения функций и сущностей к модулям.
- TA-7. Термины технической архитектуры.
- TA-8. Решение по GATE-02 и заключение к GATE-03.

### sigma-gates — правила гейтов GATE-01–GATE-06

- G-1. Пакет гейта.
- G-2. Форма заключения роли без собственного навыка.
- G-3. Запись решения по гейту.

## Основание

Конституция разработки СИГМА.MES+ редакции 0.9 (черновик) и Регламент функциональной приёмки редакции 0.1 (черновик). Дословные извлечения — в `skills/<навык>/references/constitution.extract.yaml` и `acceptance-regulation.extract.yaml`.

## Установка

См. `INSTALL.md`.

## Предупреждение

ИИ не принимает решений (RULE-AI-001). Плагин готовит материалы, рекомендации и проверки. Термин и его статус, включение требования, исход функциональной приёмки, решение по гейту, остаточный риск и выпуск записываются только как дословная цитата реплики человека в соответствующей роли; без такой реплики поле остаётся незаполненным.
