# История версий

## 0.11.1

Плагин стал полностью самодостаточным — решение ROLE-PROCESS-OWNER от 2026-09-29 (Q-103).

- Протокол сеанса больше ничего не требует от пользователя. Ни один шаг S1–S6 не
  останавливает работу: без доступа к файлам артефакт выдаётся в ответе, без
  `sigma-mes.config.yaml` навык работает без него, основание — встроенные извлечения
  Конституции 0.9 и Регламента приёмки 0.1, без опубликованных условий применения ИИ и без
  реестра терминов работа продолжается с отметкой в артефакте.
- Новое правило R11: материалы пользователя — описание сервиса, «Конституция сервиса»,
  заметки, прежние артефакты — принимаются на вход, из них берутся ответы.
- Новое правило R12: модуль вне состава M01–M13 не блокирует работу — одна строка
  предупреждения, что модуль не входит в Конституцию, и работа в полном объёме. Нужно для
  проработки идей и гипотез масштабирования.
- Без реестра терминов термины сверяются с приложением A встроенной Конституции.
- Функциональная приёмка без PASS и описания разработчика готовится как проект; исход по
  RULE-ACCEPTANCE-004 не предлагается до появления обеих предпосылок.
- Проверка S-07 охраняет самодостаточность: блокирующая формулировка в шагах протокола —
  ошибка приёмки.

## 0.11.0

- Переход на переносимый формат Agent Plugins для ChatGPT (режимы Codex и Work) и Codex: `plugin.json` в корне плагина, навыки в `skills/<имя>/SKILL.md`, настройки OpenAI — в `extensions.com.openai`.
- Роли по Конституции разработки СИГМА.MES+ редакции 0.9: ROLE-PRODUCT-OWNER, ROLE-FUNCTIONAL-ARCHITECT, ROLE-TECHNICAL-ARCHITECT. Один навык — одна роль.
- Добавлен навык гейтов `sigma-gates`: пакет гейта с блокирующими пунктами, формы заключений ролей без собственного навыка, запись решения ответственной роли.
- Общие справочники ведутся в `plugin-src/shared/` и копируются в `references/` каждого навыка скриптом `build/codex/sync-shared.sh`.
- Артефакты — Markdown с YAML-шапкой; для каждого типа есть JSON Schema и шаблон.
- Поколение 0.10.x для Claude Code удалено из репозитория решением ROLE-PROCESS-OWNER
  от 2026-09-28: оно построено на Конституции 0.8 и на кодах ролей, выведенных из
  употребления редакцией 0.9 (перечень и замены — в `references/deprecated.yaml`), и
  потому противоречит действующей Конституции. Прежнее содержимое доступно в теге
  `v0.10.1` и в истории git.
