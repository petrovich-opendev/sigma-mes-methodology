# sigma-mes-skills 0.11.5

## Назначение

Плагин готовит материалы ролей Конституции разработки СИГМА.MES+ и пакеты гейтов в формате Agent Plugins — для ChatGPT для десктопа (установка в режимах Codex или Work; навыки работают и в обычном режиме чата, и в проекте чата) и Codex CLI 0.146.0 и новее. Расширение Codex для IDE плагины не поддерживает — там навыки подключаются копированием, см. `INSTALL.md`.

**Плагин самодостаточен.** Конституция разработки 0.9, Регламент функциональной приёмки 0.1, коды, схемы и шаблоны артефактов лежат внутри него. Установили — работаете: подгружать документы, создавать конфигурацию или подключать сервисы не нужно. Материалы пользователя — описание сервиса, заметки, прежние артефакты — навык принимает на вход. Модуль СИГМА.MES+ вне состава M01–M13 не блокирует работу: навык одной строкой предупреждает, что модуль не входит в Конституцию, и продолжает — это нужно для проработки гипотез масштабирования. Отдельный продукт или сервис пользователя — не новый модуль, о нём навык не предупреждает.

**Сначала общая картина, потом детали.** Каждый режим начинает с карты на одном экране — схема Mermaid и короткая таблица, — а затем детализирует по одному блоку. Согласуются уровни целиком, а не строки: перечни длиннее 7 пунктов на подтверждение не выносятся, за ответ — не больше 3 развилок с вариантами и рекомендацией, остальное — помеченные предположения. Функциональный архитектор сам предлагает макеты экранов, когда детализирует блок.

## Условия ролей

Роль может дополнять правила Конституции собственными условиями в пределах своих полномочий:
порядок работы, проверки, форматы, условия перехода через гейт. Общее правило: разрешено всё,
что явно не запрещено и не задекларировано Конституцией; при противоречии действует
Конституция.

1. Роль готовит условие в своём навыке, в режиме «Предложить условие роли» (PO-8, FA-13,
   TA-9); роль без своего навыка — в режиме G-4 навыка гейтов. Навык сверяет условие с
   Конституцией и выдаёт готовую запись.
2. ROLE-AI-USE-CASE-OWNER даёт GO.
3. Запись вносится в реестр `role-conditions.yaml` (в `references/` каждого навыка) и выходит новой версией
   плагина. Навык применяет условия своей роли в указанных режимах, навык гейтов — условия
   перехода через гейт от всех ролей. Нет условий — всё работает как раньше.

## Основание

Конституция разработки СИГМА.MES+ редакции 0.9 (черновик) и Регламент функциональной приёмки редакции 0.1 (черновик). Дословные извлечения — в `skills/<навык>/references/constitution.extract.yaml` и `acceptance-regulation.extract.yaml`.

## Установка

```
codex plugin marketplace add petrovich-opendev/sigma-mes-methodology
```

Затем установка из Plugins Directory или `/plugins` и новый чат. Обновление — `codex plugin marketplace upgrade sigma-mes`. Подробно — `INSTALL.md`.

## Предупреждение

ИИ не принимает решений (RULE-AI-001). Плагин готовит материалы, рекомендации и проверки. Термин и его статус, включение требования, исход функциональной приёмки, решение по гейту, остаточный риск и выпуск записываются только как дословная цитата реплики человека в соответствующей роли; без такой реплики поле остаётся незаполненным.
