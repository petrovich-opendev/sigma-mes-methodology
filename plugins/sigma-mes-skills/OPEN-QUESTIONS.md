# Открытые вопросы

Вопросы к людям. Генерацию плагина они не блокируют: плагин читает соответствующие значения во время работы и останавливается, если их нет.

Исполнитель копирует этот файл в `plugins/sigma-mes-skills/OPEN-QUESTIONS.md` и добавляет в конец свои вопросы с номерами Q-101 и далее.

## Q-01. Утверждение условий применения ИИ

**Кому.** ROLE-AI-USE-CASE-OWNER; заключение — ROLE-SECURITY-OWNER.

**Вопрос.** Утвердить `context/ai-use-conditions.draft.yaml`: модель, клиенты, источники, классы данных, способ проверки. Получить заключение по документам ИБ СИГМА и Интер РАО (RULE-SECURITY-001).

**До решения.** Навыки не работают по проекту: шаг S5.

## Q-02. Пути в /docs

**Кому.** ROLE-DOCUMENTATION-OWNER.

**Вопрос.** Стандартная структура `/docs`. Пока пути задаёт каждый рабочий репозиторий в `sigma-mes.config.yaml`.

**Нужно.** Пути публикации:
- Конституции в MD;
- Регламента функциональной приёмки;
- Реестра назначений ролей;
- условий применения ИИ.

## Q-03. MCP реестра терминов

**Кому.** ROLE-DOCUMENTATION-OWNER (средство ведения реестра по RULE-TERM-003).

**Вопрос.**
- HTTPS-адрес MCP OpenMetadata.
- Способ выдачи токена.
- Список инструментов только для чтения для `enabled_tools`.

## Q-04. Где живёт исходник плагина

**Кому.** ROLE-PROCESS-OWNER.

**Вопрос.** Репозиторий плагина:
- в GitLab защищённого сегмента — установка через VPN, согласуется с федеративной моделью;
- или вне его.

**От ответа зависит.** Адрес в `INSTALL.md` и поле `instruction.source` условий применения ИИ.

## Q-05. Имя файла и версия Конституции

**Кому.** ROLE-DOCUMENTATION-OWNER.

**Вопрос.** Архив называется «Конституция_v1_9_0», а паспорт документа — версия 0.9. Плагин сверяет версию по паспорту (раздел 5.4). Имя файла должно не противоречить паспорту.

## Q-06. Сборка 0.10.0 для Claude Code

**Кому.** ROLE-PROCESS-OWNER.

**Вопрос.** Сохранять ли параллельно сборку для Claude Code. В 0.11.0 она не изменяется. Она построена на выведенных кодах ROLE-FUNCTIONAL-OWNER и ROLE-ARCHITECT и Конституции 0.8 и расходится с Конституцией 0.9.

## Q-07. Итог заключения роли

**Кому.** ROLE-PROCESS-OWNER.

**Вопрос.** Конституция задаёт код итога заключения только для ROLE-INDEPENDENT-REVIEWER: PASS, REWORK, STOP-RECOMMENDED. Для остальных ролей плагин пишет итог текстом (D-10). Если нужен единый код, его надо ввести в Конституцию.

## Q-08. Статус Конституции

**Кому.** ROLE-PROCESS-OWNER, ROLE-RELEASE-AUTHORITY.

**Вопрос.** Конституция 0.9 и Регламент 0.1 — черновики. Плагин опирается на опубликованные редакции. До утверждения это проекты, и в материалах плагина они так и называются.

## Q-09. Независимый рецензент не назначен

**Кому.** ROLE-PROCESS-OWNER.

**Вопрос.** По Реестру назначений ROLE-INDEPENDENT-REVIEWER не назначен, а его заключение обязательно для GATE-01, GATE-02 и GATE-06 (раздел 3.2). По разделу 3.1 отсутствие обязательного заключения исключает GO. Навык гейтов будет показывать это как блокирующий пункт во всех пакетах этих гейтов.

**Что решить.** Назначить носителя — внешнего эксперта по требованию раздела 4.2 — или изменить Конституцию.

## Q-101. Каталог плагина: отступление снято

**Кому.** ROLE-PROCESS-OWNER. **Статус: закрыто, отступления нет.**

Отступление существовало с 2026-09-28 и держалось одной причиной: по пути из D-02
(`plugins/sigma-mes-skills/`) находился плагин версии 0.10.1 для Claude Code, а правило 8
главного промпта запрещает перезаписывать существующий каталог. Плагин 0.11.0 был создан в
`plugins/sigma-mes-codex/`.

**Закрыто решением ROLE-PROCESS-OWNER от 2026-09-28:** поколение 0.10.x противоречит
Конституции 0.9 и удалено из репозитория целиком — плагин, его сборки, тесты, оснастка и
корневые документы прежней версии. Прежнее содержимое доступно в теге `v0.10.1` и в истории
git.

Путь освободился, и плагин перенесён туда, где его задаёт D-02: `plugins/sigma-mes-skills/`.
Расхождения с пакетом по этому пункту больше нет.

## Q-102. Выведенные коды в файле вопросов плагина

**Кому.** ROLE-PROCESS-OWNER.

**Отступление от пакета.** Шаг 5.6 главного промпта велит скопировать `OPEN-QUESTIONS.md`
пакета в плагин. Вопрос Q-06 этого файла дословно называет выведенные коды
ROLE-FUNCTIONAL-OWNER и ROLE-ARCHITECT. Раздел `deprecated` в
`checks/normative-checks.yaml` запрещает эти коды в файлах плагина везде, кроме
`deprecated.yaml` и извлечения Конституции. Выполнить оба требования одновременно нельзя.

**Что сделано.** В `check_normative.py` список `allowed_only_in` расширен файлом
`OPEN-QUESTIONS.md` плагина — по той же причине, по которой в нём уже есть
`deprecated.yaml`: предмет этого файла и есть выведенные коды. Существо правила не
ослаблено: навыкам, схемам, шаблонам и примерам эти коды по-прежнему запрещены, и проверка
это контролирует. Отступление помечено комментарием в самом скрипте.

**Что решить.** Внести `OPEN-QUESTIONS.md` в `allowed_only_in` следующей редакции пакета,
либо переписать Q-06 без употребления кодов, либо не копировать файл вопросов в плагин.
