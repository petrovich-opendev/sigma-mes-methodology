# Установка sigma-mes-skills 0.11.1

Плагин самодостаточен: Конституция разработки 0.9, Регламент функциональной приёмки 0.1,
коды, схемы и шаблоны артефактов лежат внутри него. Установили — можно работать. Никаких
файлов подгружать и ничего настраивать для начала работы не нужно.

## 1. Требования

ChatGPT для десктопа (режимы Codex или Work) либо Codex CLI или IDE. Работать можно и в
обычном режиме чата, и в проекте чата: без доступа к рабочему репозиторию навык выдаёт
артефакты целиком в ответе, сохраняете их вы.

## 2. Подключение маркетплейса

```
codex plugin marketplace add <HTTPS-адрес репозитория плагина>
```

Затем установка из Plugins Directory в десктопном приложении или через `/plugins` в Codex. После обновления плагина — перезапуск приложения.

## 3. Начало работы

Запустите любой навык. Он покажет список ролей и попросит выбрать; дальше каждый ответ
начинается строкой `Активная роль: …`. Прикладывайте любые свои материалы — описание
сервиса, заметки, выгрузки, прежние артефакты: навык берёт из них ответы и не переспрашивает
то, что там уже есть.

Модуль вне состава M01–M13 — не препятствие: навык одной строкой предупредит, что модуль не
входит в Конституцию, и продолжит работу. Это предусмотрено для проработки идей и гипотез
масштабирования.

## 4. Необязательно: реестр терминов

Без реестра навык сверяет термины с приложением A встроенной Конституции. Если в вашей среде
есть MCP-сервер реестра терминов, его можно подключить в `~/.codex/config.toml`:

```toml
[mcp_servers.sigma_terms]
url = "<HTTPS-адрес MCP реестра терминов>"        # сообщает ROLE-DOCUMENTATION-OWNER
bearer_token_env_var = "SIGMA_TERMS_TOKEN"        # токен хранится только в переменной окружения
default_tools_approval_mode = "writes"            # инструменты не только для чтения требуют подтверждения
required = false
```

Список инструментов посмотреть командой `/mcp` и оставить в `enabled_tools` только
инструменты чтения. Запрещено записывать токен в файлы репозитория.

## 5. Необязательно: сохранение в рабочий репозиторий

Если хотите, чтобы навык сам сохранял артефакты в репозиторий документации и сверял
встроенную Конституцию с опубликованной, скопируйте `references/config-template.yaml`
любого навыка в корень рабочего репозитория как `sigma-mes.config.yaml` и заполните нужные
пути. Незаполненные пути навык просто пропускает: работа от этого не останавливается.

## 6. Условия применения ИИ

RULE-AI-001 требует, чтобы ИИ применялся в условиях, разрешённых ROLE-AI-USE-CASE-OWNER.
Если условия опубликованы и путь к ним задан в `sigma-mes.config.yaml`
(`paths.ai_use_conditions`), навык их соблюдает. Если нет — навык работает, а в каждом
артефакте отмечает, что он подготовлен без утверждённых условий: такой материал — проект,
его утверждает профильная роль.
