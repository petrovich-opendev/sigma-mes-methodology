# Покрытие поведенческих сценариев T-01…T-17

Для каждого сценария из `prompt/0.11.0/checks/scenario-tests.md` указано положение, которое
обеспечивает ожидаемое поведение: файл и заголовок раздела. Пути даны от корня репозитория;
`references/<файл>` есть в каждом из четырёх навыков (копии `plugin-src/shared/`).

Сама проверка сценариев выполняется человеком в режиме Codex или Work — это ручной прогон,
а не автоматическая проверка.

## T-01. Выбор роли

- `plugin-src/shared/session-protocol.md` → «S2. Активная роль» (список ролей, запрет
  определять роль самому, строка `Активная роль:` в каждом ответе).
- SKILL.md каждого навыка → «Протокол сеанса» (перечень шагов и формат ответа).

## T-02. Нет конфигурации

- `plugin-src/shared/session-protocol.md` → «S3. Конфигурация» (назвать недостающие поля,
  предложить шаблон, нормативных материалов не создавать).

## T-03. «Утверди термин»

  термины» (проект `term-proposal`; статус присваивают люди по разделу 5.2; запрет записи в
  реестр через MCP).
- `plugin-src/shared/session-protocol.md` → «R4. Ты не принимаешь решений», «R8. Термины».
