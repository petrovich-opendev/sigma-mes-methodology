# sigma-mes-methodology

Публичный маркетплейс плагинов Claude Code. В репозитории один плагин с одним
навыком — `product-vision-interview`. Из того же исходника (`plugins/product-vision-interview/skills/product-vision-interview/references/`)
скрипт `build/build-chatgpt.sh` собирает платформонезависимую инструкцию
`build/chatgpt-instructions.md` — тот же метод, годный для чата ChatGPT без
установки плагина.

## Для кого

Владелец продукта (`ROLE-PRODUCT-OWNER`). Навык рассчитан на диалог с этой
ролью и не подменяет собой другие роли процесса.

## Что делает навык

Ведёт структурированное интервью с владельцем продукта и переводит
первоначальную идею в продуктовую часть Vision — `description.md` (для
чтения) и `description.yaml` (машинная проекция той же модели). Работа
опирается на дерево продуктовых решений: один вопрос за ход, виден остаток
существенных вопросов, каждое положение размечено по трём осям (тип
содержания, статус подтверждения, адресат заключения) и по автору
формулировки. Подробности метода — в `references/core-method.md`.

## Чего этот навык не делает

- не принимает решение по гейту и не объявляет этап или интервью завершённым;
- не утверждает требования, техническую реализуемость, достаточность
  проверки, остаточный риск, план, срок или выпуск;
- не подставляет правдоподобное значение вместо неизвестного и не
  восстанавливает статус или содержание по памяти о прошлой сессии;
- не даёт положению большего статуса, чем позволяют правила разметки
  (см. `references/statuses.md`), под давлением собеседника;
- не выполняет работу другой дисциплины и другой роли — архитектуры,
  тестирования, планирования поставки, требований;
- не сохраняет файлы результата на диск и в git — это делает владелец
  продукта сам.

**Граница навыка одной фразой: Vision — да, Use-Case Model — нет.**

## Структура репозитория

```
.claude-plugin/marketplace.json          — описание маркетплейса
plugins/product-vision-interview/        — плагин
  .claude-plugin/plugin.json
  skills/product-vision-interview/
    SKILL.md                             — порядок работы навыка
    references/                          — методические справочники
    examples/                            — два эталонных диалога
    templates/                           — пустые шаблоны description.md/.yaml
build/build-chatgpt.sh                   — сборка инструкции для ChatGPT
build/chatgpt-instructions.md            — собранный результат (коммитится)
tests/scenarios.md                       — одиннадцать сценариев проверки
tests/expected-behaviour.md              — ожидаемое поведение и метрики прогона
```

## Установка

```
/plugin marketplace add petrovich-opendev/sigma-mes-methodology
/plugin install product-vision-interview@sigma-mes-methodology
```

Подробности, включая установку вне Claude Code (через `build/chatgpt-instructions.md`)
и обновление плагина — в [INSTALL.md](INSTALL.md).
