# Методика СИГМА.MES+: плагин ролей и гейтов

Репозиторий содержит плагин `sigma-mes-skills` — навыки ролей Конституции разработки
СИГМА.MES+ и правила гейтов. Плагин готовит материалы ролей и пакеты гейтов строго по
действующим опубликованным материалам.

**ИИ не принимает решений** (RULE-AI-001). Термин и его статус, включение требования, исход
функциональной приёмки, решение по гейту, остаточный риск и выпуск записываются только как
дословная цитата реплики человека в соответствующей роли. Без такой реплики поле остаётся
незаполненным.

## Основание

- Конституция разработки СИГМА.MES+ редакции **0.9** (черновик).
- Регламент функциональной приёмки редакции **0.1** (черновик).

Дословные извлечения обоих документов лежат в плагине и служат единственным источником
ролей, правил, гейтов и терминов. Пересказов нет.

## Среда исполнения

Плагин работает только в локальном агенте с доступом к файлам рабочего репозитория:

- ChatGPT для десктопа, режимы Codex и Work;
- Codex CLI;
- Codex IDE.

Обычный режим чата для работы с проектом не используется: он работает из облака и
защищённый сегмент не видит.

## Навыки

Принцип «один навык — одна роль»; навык гейтов общий.

- **`sigma-product-owner`** — ROLE-PRODUCT-OWNER. Описание продукта, развитие работающего
  продукта, разногласия функциональных архитекторов, варианты для предприятий, ответственный
  за общие элементы функциональной архитектуры, предложение об изменении Конституции,
  заключение к гейту. Режимы PO-1…PO-7.
- **`sigma-functional-architect`** — ROLE-FUNCTIONAL-ARCHITECT. Функциональная архитектура
  модуля, исследование практик, концепт интерфейса и макеты, функциональные требования,
  требования к качеству, предметные термины, сквозные сценарии, тест-дизайн, функциональная
  приёмка, изменение функциональной архитектуры, журнал вопросов. Режимы FA-1…FA-12.
- **`sigma-technical-architect`** — ROLE-TECHNICAL-ARCHITECT. Технические архитектурные
  решения (ADR), модель C4 на Structurizr DSL, архитектура развёртывания с откатом,
  обеспечение требований к качеству, интеграционная архитектура, проверка отнесения функций
  к модулям, технические термины. Режимы TA-1…TA-8.
- **`sigma-gates`** — правила гейтов GATE-01…GATE-06. Пакет гейта с блокирующими пунктами,
  формы заключений ролей без собственного навыка, запись решения ответственной роли.
  Режимы G-1…G-3.

## Структура репозитория

```
.agents/plugins/marketplace.json          — маркетплейс репозитория
plugin-src/shared/                        — единый источник общих справочников
  session-protocol.md                     — протокол сеанса: шаги S1–S6, правила R1–R10
  constitution.extract.yaml               — дословное извлечение Конституции 0.9
  acceptance-regulation.extract.yaml      — дословное извлечение Регламента приёмки 0.1
  codes.yaml                              — разрешённые коды и версии, для которых собран плагин
  deprecated.yaml                         — выведенные из употребления коды с заменами
  config-template.yaml                    — шаблон sigma-mes.config.yaml рабочего репозитория
  artifact-schemas/                        — 21 JSON Schema шапок артефактов
  templates/                              — 21 шаблон артефактов
plugins/sigma-mes-skills/                  — плагин в формате Agent Plugins
  plugin.json, README.md, INSTALL.md, CHANGELOG.md, OPEN-QUESTIONS.md
  skills/<навык>/SKILL.md                 — четыре навыка
  skills/<навык>/references/              — копии plugin-src/shared/ (создаёт sync-shared.sh)
build/codex/
  sync-shared.sh                          — раскладка общих справочников по навыкам
  extract_constitution.py                 — извлечение нормативных текстов из .docx
  checks/run-all.sh                       — приёмка плагина: структурные и нормативные проверки
prompt/0.11.0/                            — пакет промпта, по которому собран плагин
```

Общие справочники правятся только в `plugin-src/shared/`. Копии в `references/` каждого
навыка перезаписываются скриптом; править их вручную запрещено.

## Установка

См. `plugins/sigma-mes-skills/INSTALL.md`: требования, подключение маркетплейса, подключение
реестра терминов как MCP-сервера, конфигурация рабочего репозитория, проверка, условия
применения ИИ.

## Проверка

```
sh build/codex/checks/run-all.sh
```

Прогон синхронизирует общие справочники, затем выполняет структурные проверки S-01…S-12 и
нормативные: состав идентификаторов, выведенные коды, обязательные и запрещённые формулировки
в навыках, целостность решений, правила `validation` всех типов артефактов. Код возврата 0
только при отсутствии FAIL.

Требуется `python3` с `PyYAML` и `jsonschema`, а также полный клон репозитория.

## Открытые вопросы

`plugins/sigma-mes-skills/OPEN-QUESTIONS.md` — вопросы к людям, которые не блокируют работу
плагина: адрес репозитория, статус черновиков Конституции и Регламента, неназначенные роли,
отступления от пакета промпта.
